# Stonecare Solutions Website

Responsive static website for Stonecare Solutions (Private) Limited.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

No build tools or API keys are needed for the static demo.

## Deploy on Render (free static site)
1. Create or sign in to GitHub.
2. Create a new repository, for example `stonecare-solutions-website`.
3. Upload `index.html` and this `README.md` to the repository root and commit.
4. In Render, choose **New +** → **Static Site** and connect the repository.
5. Set the branch to `main`.
6. Set **Build Command** to blank (or `echo "Static site"` if the UI requires a value).
7. Set **Publish Directory** to `.` (repository root).
8. Click **Create Static Site**. Render will assign an `onrender.com` address if available.
9. After deployment, test phone, WhatsApp, email and form links on desktop and mobile.

## Enquiry form and AI assistant
- The enquiry form opens a pre-filled email draft to `stonecaresol@gmail.com`. It does not store data on a server.
- The enquiry assistant is a transparent local demo using predefined responses. It is not connected to a live generative AI model.
- To enable real AI, add a server-side endpoint (never expose an AI API key in this static page) and update the chat JavaScript to call that endpoint. Add spam protection and a privacy notice before collecting customer data.
